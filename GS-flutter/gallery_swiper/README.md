# GallerySwiper (Flutter)

Flutter migration of the GallerySwiper Android app. Pick specific photos or
scan the full library, swipe right to keep, swipe left to mark for deletion,
undo decisions, and request safe bulk deletion through the operating system.

## Run

```sh
flutter pub get
flutter run
```

Photo-library behavior should be tested on a physical Android or iOS device.
